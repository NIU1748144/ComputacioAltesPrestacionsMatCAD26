Datasets description:

OPTDIGITS:
Set composed of images of handwritten digits (0-9).
Can be obtained at https://www.kaggle.com/datasets/zwangm/optdigits and
it's already in textual format ('0' background, '1' number)
     946 32x32 test images
    1934 32x32 train images
Currently it does not includes these files and has been not updated in the last 4
years.

MNIST:
Set composed of images of handwritten digits (0-9).
It looks to be obtained from the original Yann Lecun MNIST dataset https://www.kaggle.com/datasets/hojjatk/mnist-dataset 
It's already in textual format ('0' background, '1' number)
    5000 32x32 test images
    55000 32x32 train images
